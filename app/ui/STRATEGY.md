# UI 모듈 구현 전략
1. Dear PyGui 기반 메인 윈도우/Node Editor 구조 설계
2. 메뉴/다이얼로그/상태바 등 UI 컴포넌트 분리 및 이벤트 핸들러 구조화
3. 노드 템플릿 로딩 후 Node 메뉴 동적 생성, 노드 추가/삭제/편집 기능 구현
4. 파일 입출력(다이얼로그 포함) 기능을 core와 연동
5. 실행(Execute) 버튼 동작: 검증 → 플러그인 호출 → 결과 표시
6. 에러/상태/결과 토스트 메시지 일관 처리
7. UI 테스트: 노드 추가/삭제, 파일 저장/불러오기, 실행 결과 확인 등
8. 확장성: 메뉴/상태바/토스트 등 컴포넌트별 분리, 템플릿 리프레시 지원
