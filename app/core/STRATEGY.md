# Core 모듈 구현 전략
1. 그래프 데이터 모델(노드/링크/속성/메타데이터) 클래스 설계
2. 노드 템플릿 YAML 로딩/검증: 스키마 기반, 중복/타입/제약조건 체크
3. .process 파일 입출력: 직렬화/역직렬화, core와 UI 연동
4. 실시간 검증: 노드/링크 추가/편집 시 즉시 검증, 에러 반환
5. 전체 검증 파이프라인: 저장/실행 시 템플릿+그래프+속성 일괄 체크
6. 순환(cycle) 검출 알고리즘 구현, 정책별 처리
7. 확장성: 템플릿/그래프 스키마 변경 대응, 테스트 케이스 분리
8. 테스트: 템플릿 로딩/그래프 검증/입출력/순환 검출 등 단위 테스트 작성
