# Plugins 모듈 구현 전략
1. 플러그인 인터페이스(Executor: validate, execute) 명확화 및 샘플 구현
2. 동적 로딩(importlib 등 활용), 플러그인 경로 관리
3. 실행 시 그래프 전달, 결과 dict 반환 구조 통일
4. 플러그인 예외 처리: try/except, 에러 메시지 UI 연동
5. cycle 지원 정책: supports_cycles 속성 활용, core와 연동
6. 결과(로그/메트릭/아티팩트 등) 구조화, UI와 연동
7. 샘플 플러그인/테스트 플러그인 제공, 테스트 케이스 작성
8. 확장성: 플러그인별 추가 기능(파라미터, 아티팩트 등) 대응 구조 설계
